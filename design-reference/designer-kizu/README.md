# Designer reference — original KIZU screens

Drop the product designer's screens here (PNG/JPG, any filenames).

These are the visual target: background treatment, glass surfaces, content
layout and icon placement. `../../onboarding-flow/flow-tentzu.jpeg` is an
earlier, lower-resolution capture of the same direction.

Note: do NOT hand these over via macOS screenshot-preview temp paths
(`/var/folders/.../TemporaryItems/NSIRD_screencaptureui_*`). The OS purges
those the moment the preview thumbnail is dismissed, so the files are gone
before they can be copied.
